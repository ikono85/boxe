# Sons personnalisés

Déposez ici un fichier `.mp3`, `.ogg`, `.wav`, `.m4a` ou `.webm` portant le nom d'une clé
ci-dessous : il remplace automatiquement le son synthétisé (détection au build par Vite).

| Fichier | Moment |
| --- | --- |
| `punch_jab` | élan d'un jab |
| `punch_cross` | élan d'un direct |
| `punch_hook` | élan d'un crochet |
| `punch_uppercut` | élan d'un uppercut |
| `whiff` | coup dans le vide |
| `dodge` | esquive |
| `exhale` | souffle du boxeur au moment du coup |
| `impact_head` | impact au visage |
| `impact_body` | impact au corps |
| `impact_heavy` | coup critique |
| `hit_received` | coup reçu par le joueur |
| `block` | coup bloqué |
| `ko` | coup du KO |
| `ringing` | bourdonnement quand on est sonné |
| `combo` | combo réussi |
| `bell` | cloche du round |
| `clapper` | claquoir des 10 dernières secondes |
| `crowd_ambience` | ambiance du public (en boucle) |
| `crowd_cheer` | ovation |
| `crowd_ooh` | « oooh » du public |
| `heartbeat` | battement de cœur (vie basse) |
| `breath` | respiration (essoufflé) |
| `ui_click`, `ui_hover` | interface |

Volumes et catégories : `src/audio/SoundLibrary.js`.
